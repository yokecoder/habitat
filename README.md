# Habitat

A modern productivity application that combines habit tracking and task management into a single, minimalist workspace. Habitat helps users build consistent routines, track daily progress, and manage tasks efficiently while maintaining a clean and distraction-free experience.

## 🌐 Live Demo

https://habitat-nu.vercel.app/

## 🚀 Overview

Habitat is designed to improve personal productivity by providing two essential tools in one application:

* Habit tracking for building positive routines
* Task management for organizing daily activities

The application focuses on simplicity, speed, and usability, making it easy for users to stay consistent with their goals.

## ✨ Features

### Habit Tracking

* Create and manage habits
* Track daily progress
* Build consistency through streaks
* Monitor habit completion

### Task Management

* Create and organize tasks
* Mark tasks as completed
* Manage daily responsibilities
* Simple and intuitive workflow

### User Experience

* Clean and minimalist interface
* Responsive design for mobile and desktop
* Fast and lightweight performance
* Progressive Web App (PWA) support

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* Vite
* CSS3
* HTML5

## 🎯 Why Habitat?

Many productivity apps become cluttered with unnecessary features. Habitat focuses on the essentials—helping users build habits and complete tasks without distractions.
